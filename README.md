# Layout CSS Grid **WILDBEAST**

Site institucional de página única sobre a vida selvagem dos lobos, com a marca fictícia **Wildbeast**. Desenvolvido como projeto prático de curso intensivo de **CSS Grid Layout**, focando em estruturação completa de páginas com Grid puro (sem Flexbox), do zero até um layout 100% responsivo.

## **Funcionalidades Principais**
- **Header**: Cabeçalho fixo com logo e navegação.
- **Sidenav**: Menu lateral de navegação por seções.
- **Conteúdo em Grid**: Áreas de características e atributos organizadas via Grid Template Areas.
- **Anúncios e Footer**: Seções complementares estruturadas em grid.
- **Design Responsivo**: Adaptação completa de grid, menu e conteúdo para diferentes tamanhos de tela via media queries.

## **Tecnologias e Skills Aplicadas**

| **Skill** | **Descrição** | **Exemplo no Projeto** |
|-----------|---------------|------------------------|
| **HTML5** | Estrutura semântica da página | `index.html` |
| **CSS Grid Layout** | Display grid, template columns/rows/areas, gap, auto flow, auto columns/rows | `style.css` - estrutura geral, header, sidenav, footer |
| **Grid Alinhamento** | Justify/Align Content e Justify/Align Items/Self | Alinhamento dos blocos de conteúdo |
| **Layout Responsivo** | Media queries adaptando grid e menu | Grid responsivo, menu responsivo, conteúdo responsivo |
| **Git/GitHub** | Versionamento com commits + GitHub Pages ativo | Histórico completo + deploy live |

Prática hands-on de **CSS Grid Layout** completo: desde os conceitos fundamentais (display grid, template columns/rows/areas, gap, auto flow, alinhamentos) até a aplicação real na construção de um site completo (header, sidenav, conteúdo, anúncios e footer), finalizando com responsividade total.
